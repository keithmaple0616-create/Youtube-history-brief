# Roadmap

## Phase 1: MVP

Focus:

Manual current-event input to English script generation.

Features:

- Event intake.
- Topic angle generation.
- Topic scoring.
- Historical parallel generation.
- Chinese lens generation.
- YouTube packaging.
- Outline generation.
- English script generation.

Goal:

Create a useful topic package and script draft from one manually entered current event.

## Phase 2: Research and Packaging

Focus:

Improve credibility, research quality, and YouTube packaging.

Features:

- Source collection.
- Citation management.
- Claim verification checklist.
- Thumbnail concept generation.
- Shorts extraction.
- Community post generation.
- Newsletter summary generation.

Goal:

Make each script easier to verify, package, and repurpose.

## Phase 3: News Discovery

Focus:

Help the creator find promising topics proactively.

Features:

- Current event feed.
- Topic trend monitoring.
- Relevance filters.
- Hotness vs. depth ranking.
- Watchlist for recurring themes.

Goal:

Turn the tool into a weekly topic strategist.

## Phase 4: Channel Memory and Analytics

Focus:

Use the creator's own channel history to improve future outputs.

Features:

- Published video archive.
- Title performance notes.
- Audience comments summary.
- Avoid repeated topics.
- Learn preferred tone and structure.
- A/B title suggestions.

Goal:

Make the tool increasingly aligned with the creator's actual channel.

## Phase 5: Production Workflow

Focus:

Support the broader video production process.

Features:

- Shot list and B-roll planning.
- Visual asset prompts.
- Editing notes.
- Teleprompter export.
- YouTube description and tags.
- Publishing checklist.

Goal:

Move from script assistant to end-to-end creator operating system.
