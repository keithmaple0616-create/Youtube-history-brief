# Roadmap

## Phase 1: MVP

Focus:

Manual current-event input to English script generation.

Features:

- Event intake.
- Topic angle generation.
- Topic scoring.
- Historical parallel generation.
- Chinese lens generation.
- YouTube packaging.
- Outline generation.
- English script generation.

Goal:

Create a useful topic package and script draft from one manually entered current event.

## Phase 2: Research and Packaging

Focus:

Improve credibility, research quality, and YouTube packaging.

Features:

- Source collection.
- Citation management.
- Claim verification checklist.
- Thumbnail concept generation.
- Shorts extraction.
- Community post generation.
- Newsletter summary generation.

Goal:

Make each script easier to verify, package, and repurpose.

## Phase 3: News Discovery

Focus:

Help the creator find promising topics proactively.

Features:

- Current event feed.
- Topic trend monitoring.
- Relevance filters.
- Hotness vs. depth ranking.
- Watchlist for recurring themes.

Goal:

Turn the tool into a weekly topic strategist.

## Phase 4: Channel Memory and Analytics

Focus:

Use the creator's own channel history to improve future outputs.

Features:

- Published video archive.
- Title performance notes.
- Audience comments summary.
- Avoid repeated topics.
- Learn preferred tone and structure.
- A/B title suggestions.

Goal:

Make the tool increasingly aligned with the creator's actual channel.

## Phase 5: Separate Video Production Tool

Focus:

Support the broader video production process after a final script is approved, but keep it outside the Brief MVP so it can serve other content lanes.

Features:

- Script-to-visual-beat conversion.
- Evidence / diagram / generated illustration / atmosphere classification.
- Per-episode asset plan instead of a universal footage library.
- Manual image2 prompt package for Codex-based image generation.
- Diagram specs for maps, timelines, charts, and relationship graphics.
- Caption and kinetic-emphasis plan.
- Later: HyperFrames or Remotion assembly.

Goal:

Move from script assistant to a reusable visual planning workflow without making the Brief tool responsible for video production.

## Phase 6: Creator Operating System

Focus:

Connect strategy, writing, production, packaging, and channel memory.

Features:

- Teleprompter export.
- Publishing checklist.
- Published video archive.
- Performance notes.
- Comment summaries.
- Reusable asset and topic memory.

Goal:

Make the tool increasingly aligned with the creator's actual channel and production habits.
