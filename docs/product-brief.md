# YouTube Historical Current Affairs Tool - Product Brief

## Project Context

The creator wants to build a long-form YouTube channel for North American audiences. The channel uses current political and social events as the entry point, then explains a related historical event or historical pattern. The differentiator is the creator's Chinese background: Chinese history, political culture, and civilizational concepts are used as an analytical lens for issues that North American viewers already care about.

The product is a creator tool that helps move from a manually entered current event to an English long-form YouTube script.

## Channel Positioning

Working positioning:

> Current events through historical memory, with a Chinese civilizational lens.

Chinese summary:

> 从热点看历史，从中国经验看西方困境。

The channel should not feel like propaganda, partisan commentary, or generic history education. It should feel like historically informed political and cultural analysis for curious North American viewers.

## Core Content Formula

Each video should follow this logic:

1. Start with a current North American or globally relevant event.
2. Identify the deeper political, social, or cultural question behind the event.
3. Connect the question to one or more historical parallels.
4. Add a Chinese historical or cultural lens that North American audiences may not normally encounter.
5. Explain similarities and differences carefully.
6. End with a useful, surprising, or clarifying insight about the present.

Short formula:

> Current event -> Historical analogy -> Chinese lens -> North American relevance.

## Audience

Primary audience:

- North American English-speaking viewers.
- Interested in politics, history, geopolitics, culture, and institutions.
- Curious but not necessarily academic.
- Tired of shallow partisan commentary.
- Open to non-Western perspectives if presented clearly and honestly.

Secondary audience:

- Chinese diaspora viewers.
- International relations and history enthusiasts.
- Newsletter, podcast, and essay audiences interested in civilizational comparison.

## Product Vision

Build a tool that helps the creator consistently generate strong long-form YouTube topics and scripts from manually entered current events.

The tool should initially act as a "topic strategist" and "script assistant", not a fully automated content factory.

## MVP Scope

The current stage focuses only on:

> Manual current-event input -> topic strategy -> outline -> English long-form script.

Out of scope for MVP:

- Automatic news scraping.
- YouTube Studio integration.
- Thumbnail image generation.
- Performance analytics.
- Team collaboration.
- Automated publishing.

## MVP User Flow

1. User manually enters a current event, short description, or article link.
2. Tool generates several topic angles.
3. Tool scores each angle.
4. User chooses one angle.
5. Tool generates YouTube packaging options.
6. Tool generates a structured long-form outline.
7. User adjusts or approves the outline.
8. Tool generates an English script.
9. Tool optionally generates shorts ideas and supporting notes.

## Key Output: Topic Package

For each manually entered current event, the tool should be able to produce a topic package with:

- 5 topic angles.
- Score for each topic angle.
- Recommended title options.
- Opening hook.
- Historical parallels.
- Chinese historical or cultural lens.
- Risks and weak analogies.
- Long-form video outline.
- Suggested English script direction.

## Product Principle

The most valuable early capability is not generating many words. It is improving topic judgment.

The tool should help answer:

- Is this event worth turning into a long video?
- What is the deeper historical question?
- What would make this different from ordinary political commentary?
- What Chinese historical lens is genuinely useful here?
- What analogy is tempting but misleading?
