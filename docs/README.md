# Project Memory

This folder preserves the product thinking for the YouTube historical current affairs script tool.

Read these files when resuming the project:

- `product-brief.md`: overall concept, channel positioning, and product vision.
- `mvp-requirements.md`: current-stage requirements from manual input to English script generation.
- `content-framework.md`: channel voice, content formula, Chinese lenses, and topic standards.
- `roadmap.md`: long-term product phases.
- `decision-log.md`: important decisions and why they were made.

Current MVP:

> Manual current-event input -> topic strategy -> outline -> English long-form script.
